### Fase 2 - Contexto

1. 
Você é um desenvolvedor experiente em .NET e Vue.js, com um forte entendimento de práticas de desenvolvimento modernas, incluindo o uso de minimal APIs, logging eficiente e gerenciamento de configuração com dotenv.

Seu objetivo é criar uma aplicação de lista de tarefas (todo list) que seja simples e bem estruturada, utilizando as melhores práticas para garantir que o código seja limpo, eficiente, didático e fácil de manter.

A aplicação deve ser dividida em duas partes: uma API minimal em ASP.NET para o backend e um front-end em Vue.js para a interface do usuário. A comunicação entre o frontend e o backend deve ser feita de forma eficiente, utilizando JSON para troca de dados.

Utilize um banco de dados leve, como SQLite, para armazenar as tarefas, e implemente operações CRUD (Create, Read, Update, Delete) para gerenciar as tarefas.

Crie um método de autenticação básico para apenas um usuário (admin/admin).

Adicione logs estruturados no backend e no frontend para monitorar as requisições e ações do usuário, utilizando o nível de log definido em arquivos .env para controlar a verbosidade dos logs.

Utilize o dotenv para configurar as URLs, portas e níveis de log tanto no backend quanto no frontend, garantindo que a aplicação seja facilmente configurável e adaptável a diferentes ambientes.

Por fim as aplicações devem ser conteinerizadas usando Docker, com um arquivo Docker Compose para facilitar a orquestração dos serviços.


2. 
Para os dois containers, crie o .dockerignore para evitar que arquivos desnecessários sejam copiados para a imagem, como arquivos de configuração local, arquivos de log e pastas de dependências.
Use dotnet 10 para o backend
Use a última versão lts do node para o frontend através do nvm. Se o nvm não estiver instalado, instale-o e use-o para gerenciar as versões do Node.js.
Configure o Docker Compose para orquestrar os dois containers, garantindo que o backend e o frontend sejam iniciados na ordem correta e possam se comunicar entre si.

3. 
Certifique-se de que a aplicação seja testada localmente antes de criar as imagens Docker, para garantir que tudo esteja funcionando corretamente. Utilize ferramentas de teste adequadas para o backend e o frontend, como xUnit para o backend e Jest, Playwright, ou qualquer outro framework de teste para o frontend que seja compatível com Vue.js.

4. 
Não use NVM no Dockerfile, pois o NVM é projetado para ser usado em ambientes de desenvolvimento e não é recomendado para uso em ambientes de produção ou dentro de contêineres. Em vez disso, use a imagem oficial do Node.js que já inclui a versão desejada do Node.js.
